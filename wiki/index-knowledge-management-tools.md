# Knowledge Management Tools

- [Atomic Server](atomic-server.md) — Knowledge graph database with documents (similar to Notion), tables, search, and a powerful linked data API. Lightweight, very fast and no runtime…
- [Digimindmap](digimindmap.md) — Create simple mindmaps (documentation in French). (Demo, Source Code) AGPL-3.0 Nodejs/PHP
- [LibreKB](librekb.md) — Web-based knowledge base solution. A simple web app, it runs on pretty much any web server or hosting provider with PHP and MySQL. (Source Code) GPL-3.0 PHP
- [Marmot](marmot.md) — Data catalog for discovering and organizing data assets across your stack, including databases, APIs, message queues, and pipelines. (Demo, Source Code) MIT…
- [memEx](memex.md) — Structured personal knowledge base, inspired by zettlekasten and org-mode. (Source Code) AGPL-3.0 Docker
- [SiYuan](siyuan.md) — Privacy-first personal knowledge management software, written in typescript and golang. (Source Code) AGPL-3.0 Docker/Go
- [TeamMapper](teammapper.md) — Host and create your own mindmaps. Share your mindmap sessions with your team and collaborate live on mindmaps. (Demo) MIT Docker/Nodejs
