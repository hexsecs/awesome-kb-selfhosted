# DNS

- [AdGuard Home](adguard-home.md) — User-friendly ads & trackers blocking DNS server. (Source Code) GPL-3.0 Docker
- [blocky](blocky.md) — Fast and lightweight DNS proxy as ad-blocker for local network with many features (alternative to Pi-hole). (Source Code) Apache-2.0 Go/Docker
- [Maza ad blocking](maza-ad-blocking.md) — Local ad blocker. Like Pi-hole but local and using your operating system. (Source Code) Apache-2.0 Shell
- [Numa](numa.md) — Ad-blocking DNS resolver with DNSSEC-validating recursive resolution, DoH/DoT/Oblivious DoH, ephemeral overrides, and local service domains, in a single…
- [Pi-hole](pi-hole.md) — Blackhole for Internet advertisements with a GUI for management and monitoring. (Source Code) EUPL-1.2 Shell/PHP/Docker
- [Technitium DNS Server](technitium-dns-server.md) — Authoritative/recursive DNS server with ad blocking functionality. (Source Code) GPL-3.0 Docker/C#
