# File Transfer - Peer-to-peer Filesharing

- [bittorrent-tracker](bittorrent-tracker.md) — Simple, robust, BitTorrent tracker (client and server) implementation. (Source Code) MIT Nodejs
- [DashBeam](dashbeam.md) — File transfer tool with peer-to-peer networking, letting you transfer any file with any size. (Demo, Source Code) AGPL-3.0 deb/Docker
- [Deluge](deluge.md) — Lightweight, cross-platform BitTorrent client. (Source Code) GPL-3.0 Python/deb
- [PrivyDrop](privydrop.md) — Simple and user-friendly, breakpoint-resumable peer-to-peer text, image, and file transfer tool based on WebRTC. (Source Code) MIT Docker/Nodejs
- [qBittorrent](qbittorrent.md) — Free cross-platform bittorrent client with a feature rich Web UI for remote access. (Source Code) GPL-2.0 C++
- [slskd](slskd.md) — Modern client-server application for the Soulseek file sharing network. AGPL-3.0 Docker/C#
- [Transmission](transmission.md) — Fast, easy, free Bittorrent client. (Source Code) GPL-3.0 C++/deb
- [Webtor](webtor.md) — Web-based torrent client with instant audio/video streaming. (Demo) MIT Docker
