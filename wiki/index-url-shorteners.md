# URL Shorteners

- [bit](bit.md) — Fast, lightweight, resource-efficient, compiled URL shortener. MIT Docker/Crystal
- [Chhoto URL](chhoto-url.md) — Simple, lightning-fast URL shortener with no bloat (fork of simply-shorten). (Demo, Source Code, Clients) MIT Rust/Docker
- [clink](clink.md) — Super-minimal link shortening service written in pure C, focusing on small executable size, portability, and ease of configuration. (Demo) AGPL-3.0 C
- [Flink](flink.md) — Create QR Codes, embeddable link previews for your website and crawls/scrapes metadata. (Demo) MIT Docker
- [Kutt](kutt.md) — Modern URL shortener with support for custom domains and custom URLs. (Demo, Source Code) MIT Nodejs/Docker
- [rs-short](rs-short.md) — Lightweight link shortener written in Rust, with features such as caching, spambot protection and phishing detection. (Demo) MPL-2.0 Rust
- [Shlink](shlink.md) — URL shortener with REST API and command line interface. Includes official progressive web application and docker images. (Source Code, Clients) MIT PHP/Docker
- [Simple-URL-Shortener](simple-url-shortener.md) — KISS URL shortener, public or private (with account). Minimalist and lightweight. No dependencies. (Demo) MIT PHP
- [YOURLS](yourls.md) — Set of PHP scripts that will allow you to run Your Own URL Shortener. Features include password protection, URL customization, bookmarklets, statistics…
