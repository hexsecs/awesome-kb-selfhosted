# Note-taking & Editors

- [Blinko](blinko.md) — Personal note tool with AI features. (Source Code) AGPL-3.0 Docker
- [DailyTxT](dailytxt.md) — Encrypted diary Web application to save your personal memories of each day. Includes a search function and encrypted file upload. (Demo) MIT Docker
- [Docs](docs.md) — Collaborative note taking, wiki and documentation platform that scales. (Source Code) MIT K8S
- [draw.io](draw-io.md) — Diagram software for making flowcharts, process diagrams, org charts, UML, ER and network diagrams. (Source Code) Apache-2.0 Javascript/Docker
- [flatnotes](flatnotes.md) — Database-less note-taking web app that utilises a flat folder of markdown files for storage. (Demo) MIT Docker
- [HedgeDoc](hedgedoc.md) — Realtime collaborative markdown notes on all platforms, formerly known as CodiMD and HackMD CE. (Demo, Source Code) AGPL-3.0 Docker/Nodejs
- [Joplin](joplin.md) — Note taking application with markdown editor and encryption support for mobile and desktop platforms. Runs client-side and syncs through your own Nextcloud…
- [Jotty](jotty.md) — Lightweight but powerful alternative for managing your personal, file based, notes and checklists. (Source Code) AGPL-3.0 Docker
- [Livebook](livebook.md) — Realtime collaborative notebook app based on Markdown that supports running Elixir code snippets, TeX and Mermaid Diagrams. Easily deployed using Docker or…
- [Many Notes](many-notes.md) — Markdown note-taking web application designed for simplicity. MIT Docker
- [Memos](memos.md) — Knowledge base that works with a SQLite db file. (Demo, Source Code) MIT Docker/Go
- [Neverkin](neverkin.md) — Collaborative writing, worldbuilding and D&D-session-planning app. Tools for organizing your notes and stories. (Demo, Source Code) GPL-3.0 Nodejs/Docker
- [Note Mark](note-mark.md) — Minimal web-based Markdown notes app. (Source Code) AGPL-3.0 Docker
- [NoteDiscovery](notediscovery.md) — Markdown note-taking app with plain-file storage, graph view, and MCP integration (alternative to Obsidian, Notion). (Demo, Source Code) MIT Docker/Python
- [Overleaf](overleaf.md) — Web-based collaborative LaTeX editor. (Source Code) AGPL-3.0 Ruby
- [Plainpad](plainpad.md) — Modern note taking application for the cloud, utilizing the best features of progressive web apps technology. (Demo, Source Code) GPL-3.0 PHP
- [plumio](plumio.md) — Markdown notes taking app with live preview, document encryption, multi-user support, multi-organization capabilities and more. (Demo, Source Code) AGPL-3.0…
- [SilverBullet](silverbullet.md) — Note-taking application optimized for people with a hacker mindset. (Demo, Source Code, Clients) MIT Docker/Deno
- [Standard Notes](standard-notes.md) — Simple and private notes app. Protect your privacy while getting more done. That's Standard Notes. (Demo, Source Code) GPL-3.0 Ruby
- [TriliumNext Notes](triliumnext-notes.md) — Cross-platform hierarchical note taking application with focus on building large personal knowledge bases (fork of Trilium Notes). AGPL-3.0 Nodejs/Docker/K8S
- [Turtl](turtl.md) — Totally private personal database and note taking app. (Source Code) GPL-3.0 CommonLisp
- [Writing](writing.md) — Lightweight distraction-free text editor, in the browser (Markdown and LaTeX supported). No lag when writing. (Source Code) MIT Javascript
