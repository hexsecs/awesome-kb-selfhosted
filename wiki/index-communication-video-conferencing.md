# Communication - Video Conferencing

- [BigBlueButton](bigbluebutton.md) — Supports real-time sharing of audio, video, slides (with whiteboard controls), chat, and the screen. Instructors can engage remote students with polling…
- [Galene](galene.md) — Video conferencing server that is easy to deploy and that requires moderate server resources. (Source Code) MIT Go
- [Janus](janus.md) — General-purpose, lightweight, minimalist WebRTC Server. (Demo, Source Code) GPL-3.0 C
- [Jitsi Meet](jitsi-meet.md) — WebRTC application that uses Jitsi Videobridge to provide high quality, scalable video conferences. (Demo, Source Code) Apache-2.0 Nodejs/Docker/deb
- [Jitsi Video Bridge](jitsi-video-bridge.md) — WebRTC compatible Selective Forwarding Unit (SFU) that allows for multiuser video communication. (Source Code) Apache-2.0 Java/deb
- [MiroTalk C2C](mirotalk-c2c.md) — Real-time cam-2-cam video calls & screen sharing, end-to-end encrypted, to embed in any website with a simple iframe. (Source Code) AGPL-3.0 Nodejs/Docker
- [MiroTalk P2P](mirotalk-p2p.md) — Simple, secure, fast real-time video conferences up to 4k and 60fps, compatible with all browsers and platforms. (Demo, Source Code) AGPL-3.0 Nodejs/Docker
- [MiroTalk SFU](mirotalk-sfu.md) — Simple, secure, scalable real-time video conferences up to 4k, compatible with all browsers and platforms. (Demo, Source Code) AGPL-3.0 Nodejs/Docker
- [plugNmeet](plugnmeet.md) — Scalable and high performance web conferencing system. (Demo, Source Code) MIT Docker/Go
