# Blogging Platforms

- [Antville](antville.md) — Feature-rich blog hosting software which can host tens of thousands of blogs. (Source Code) Apache-2.0 Javascript
- [bloglite](bloglite.md) — Micro-blog tool offering built-in syntax highlighting, mobile publishing and more (alternative to Twitter, Bluesky). MIT Docker
- [Chyrp Lite](chyrp-lite.md) — Extra-awesome, extra-lightweight blog engine. (Source Code) BSD-3-Clause PHP
- [Dotclear](dotclear.md) — Take control over your blog. GPL-2.0 PHP
- [Ech0](ech0.md) — Lightweight federated publishing platform focused on personal idea sharing (documentation in Chinese). (Demo, Source Code) AGPL-3.0 Docker/K8S
- [FlatPress](flatpress.md) — Lightweight, easy-to-set-up flat-file blogging engine. (Source Code) GPL-2.0 PHP
- [Ghost](ghost.md) — Just a blogging platform. (Source Code) MIT Nodejs
- [Haven](haven.md) — Private blogging system with markdown editing and built in RSS reader. (Demo, Source Code) MIT Ruby
- [HTMLy](htmly.md) — Databaseless PHP blogging platform. A flat-file CMS that allows you to create a fast, secure, and powerful website or blog in seconds. (Demo, Source Code)…
- [Known](known.md) — Collaborative social publishing platform. (Source Code) Apache-2.0 PHP
- [Mataroa](mataroa.md) — Naked blogging platform for minimalists. (Source Code) MIT Python
- [PluXml](pluxml.md) — XML-based blog/CMS platform. (Source Code) GPL-3.0 PHP
- [Serendipity](serendipity.md) — Highly extensible and customizable PHP blog engine using Smarty templating (s9y). (Source Code) BSD-3-Clause PHP
- [WriteFreely](writefreely.md) — Writing software for starting a minimalist, federated blog — or an entire community. (Source Code) AGPL-3.0 Go
