# Manufacturing

- [CNCjs](cncjs.md) — Web interface for CNC milling controllers running Grbl, Smoothieware, or TinyG. (Source Code) MIT Nodejs
- [Fluidd](fluidd.md) — Lightweight & responsive user interface for Klipper, the 3D printer firmware. (Source Code) GPL-3.0 Docker/Nodejs
- [LinuxCNC](linuxcnc.md) — Linux based CNC machine controller. It can drive milling machines, lathes, 3D printers, laser cutters, plasma cutters, robot arms, hexapods, and more.…
- [Mainsail](mainsail.md) — Modern and responsive user interface for the Klipper 3D printer firmware. Control and monitor your printer from everywhere, from any device. (Source Code)…
- [Manyfold](manyfold.md) — Digital asset manager for 3d print files; STL, OBJ, 3MF and more. (Source Code) MIT Docker
- [Octoprint](octoprint.md) — Snappy web interface for controlling consumer 3D printers. (Source Code) AGPL-3.0 Docker/Python
- [Orkyo Community](orkyo-community.md) — Production scheduling for manufacturing teams — one plan for the machines, people, and tools that run your jobs. (Demo, Source Code) AGPL-3.0 C#/Docker
