# Communication - Email - Mail Transfer Agents

- [chasquid](chasquid.md) — SMTP (email) server with a focus on simplicity, security, and ease of operation. (Source Code) Apache-2.0 Go
- [Courier MTA](courier-mta.md) — Fast, scalable, enterprise mail/groupware server providing ESMTP, IMAP, POP3, webmail, mailing list, basic web-based calendaring and scheduling services.…
- [DragonFly](dragonfly.md) — Small MTA for home and office use. Works on Linux and FreeBSD. BSD-3-Clause C
- [EmailRelay](emailrelay.md) — Small and easy to configure SMTP and POP3 server for Windows and Linux. (Source Code) GPL-3.0 C++
- [Exim](exim.md) — Message transfer agent (MTA) developed at the University of Cambridge. (Source Code) GPL-3.0 C/deb
- [Haraka](haraka.md) — Fast, highly extensible, and event driven SMTP server. (Source Code) MIT Nodejs
- [OpenSMTPD](opensmtpd.md) — Secure SMTP server implementation from the OpenBSD project. (Source Code) ISC C/deb
- [Postfix](postfix.md) — Fast, easy to administer, and secure Sendmail replacement. IPL-1.0 C/deb
- [Sendmail](sendmail.md) — Message transfer agent (MTA). Sendmail C/deb
