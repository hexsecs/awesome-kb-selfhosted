# Feed Readers

- [Bubo Reader](bubo-reader.md) — Irrationally minimal RSS feed reader. (Demo) MIT Nodejs
- [CommaFeed](commafeed.md) — Google Reader inspired RSS reader. (Demo, Source Code) Apache-2.0 Java/Docker
- [Feeds Fun](feeds-fun.md) — News reader with tags, scoring, and AI. (Source Code) BSD-3-Clause Python
- [FreshRSS](freshrss.md) — Self-hostable RSS feed aggregator. (Demo, Source Code) AGPL-3.0 PHP/Docker
- [Fusion](fusion.md) — Lightweight RSS aggregator and reader. MIT Go/Docker
- [Goeland](goeland.md) — Turns any RSS/Atom feed into a beautiful email digest. MIT Go/Docker
- [JARR](jarr.md) — JARR (Just Another RSS Reader) is a web-based news aggregator and reader (fork of Newspipe). (Demo, Source Code) AGPL-3.0 Docker/Python
- [Kriss Feed](kriss-feed.md) — Simple and smart (or stupid) feed reader. CC0-1.0 PHP
- [Leed](leed.md) — Minimalist RSS aggregator (Leed stands for Light Feed). AGPL-3.0 PHP
- [Miniflux](miniflux.md) — Minimalist news reader. (Source Code) Apache-2.0 Go/deb/Docker
- [NewsBlur](newsblur.md) — Personal news reader that brings people together to talk about the world. A new sound of an old instrument. (Source Code) MIT Python
- [Newspipe](newspipe.md) — Web news reader. (Demo) AGPL-3.0 Python
- [reader](reader.md) — Feed reader web app and library (so you can use it to build your own), with only standard library and pure-Python dependencies. BSD-3-Clause Python
- [Readflow](readflow.md) — Lightweight news reader with modern interface and features: full-text search, automatic categorization, archiving, offline support, notifications. (Source…
- [RSS-Bridge](rss-bridge.md) — Generate RSS/ATOM feeds for websites which don't have one. Unlicense PHP/Docker
- [RSS Monster](rss-monster.md) — Easy to use web-based RSS aggregator and reader compatible with the Fever API (alternative to Google Reader). MIT PHP
- [RSS2EMail](rss2email.md) — Fetches RSS/Atom-feeds and pushes new content to any email-receiver, supports OPML. GPL-2.0 Python/deb
- [RSSHub](rsshub.md) — Easy to use, and extensible RSS feed aggregator capable of generating RSS feeds from pretty much everything ranging from social media to university…
- [Selfoss](selfoss.md) — New multipurpose rss reader, live stream, mashup, aggregation web application. (Source Code) GPL-3.0 PHP
- [Stringer](stringer.md) — Work-in-progress, anti-social RSS reader that. MIT Ruby
- [Tiny Tiny RSS](tiny-tiny-rss.md) — Web-based news feed (RSS/Atom) reader and aggregator. (Source Code) GPL-3.0 Docker/PHP
- [TinyFeed](tinyfeed.md) — Generate a static HTML page from a collection of feeds with a simple CLI. (Demo, Source Code) MIT Go/Docker
- [Upvote RSS](upvote-rss.md) — Generate rich RSS feeds from Reddit, Hacker News, Lemmy, Mbin, and more. (Demo, Source Code) MIT Docker/PHP
- [Yarr](yarr.md) — Yarr (yet another rss reader) is a web-based feed aggregator which can be used both as a desktop application and as a personal server. MIT Go
