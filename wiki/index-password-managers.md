# Password Managers

- [AliasVault](aliasvault.md) — End-to-end encrypted password manager with a built-in email alias generator and server. (Source Code) MIT Docker
- [Bitwarden](bitwarden.md) — Password manager with a webapp, browser extension, and mobile app. (Source Code) AGPL-3.0 Docker/C#
- [Passbolt](passbolt.md) — Collaborative password manager. (Source Code) AGPL-3.0 PHP/deb/K8S/Docker
- [PassIt](passit.md) — Simple password manage with sharing features by group and user, but no administration interface. (Demo, Source Code) AGPL-3.0 Docker/Python
- [Psono](psono.md) — Password manager for companies. (Demo, Source Code) Apache-2.0 Python

- [Vaultwarden](vaultwarden.md) — Lightweight Bitwarden server API implementation written in Rust. GPL-3.0 Rust/Docker
