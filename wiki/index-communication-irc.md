# Communication - IRC

- [Ergo](ergo.md) — Modern IRCv3 server written in Go, combining the features of an ircd, a services framework, and a bouncer. (Source Code) MIT Go/Docker
- [Glowing Bear](glowing-bear.md) — Web frontend for WeeChat. (Demo) GPL-3.0 Nodejs
- [InspIRCd](inspircd.md) — Modular IRC server written in C++ for Linux, BSD, Windows, and macOS. (Source Code) GPL-2.0 C++/Docker
- [Kiwi IRC](kiwi-irc.md) — Responsive web IRC client with theming support. (Demo, Source Code) Apache-2.0 Nodejs
- [ngircd](ngircd.md) — Portable and lightweight Internet Relay Chat server for small or private networks. (Source Code) GPL-2.0 C/deb
- [Quassel IRC](quassel-irc.md) — Distributed IRC client, meaning that one (or multiple) client(s) can attach to and detach from a central core. (Source Code) GPL-2.0 C++
- [Robust IRC](robust-irc.md) — IRC without netsplits. Distributed IRC server, based on RobustSession protocol. (Source Code) BSD-3-Clause Go
- [The Lounge](the-lounge.md) — Web IRC client. (Demo, Source Code) MIT Nodejs/Docker
- [UnrealIRCd](unrealircd.md) — Modular, advanced and highly configurable IRC server written in C for Linux, BSD, Windows, and macOS. (Source Code) GPL-2.0 C
- [Weechat](weechat.md) — Fast, light and extensible chat client. (Source Code) GPL-3.0 C/Docker/deb
- [ZNC](znc.md) — Advanced IRC bouncer. (Source Code) Apache-2.0 C++/deb
